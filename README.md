# Fort Wayne / Allen County Scraper

Standalone motivated-seller intelligence dashboard for Fort Wayne, Indiana and Allen County.

This repository is separate from `208-ndo/akron-summit-scraper`. The first build is a static dashboard shell using three fake normalized sample leads only. It does not scrape live public sites yet.

Public site target:

`https://208-ndo.github.io/fort-wayne-allen-scraper/`

## Current Build

- Static dashboard: `index.html`
- Sample data: `data/records.json`
- Public source plan: `SOURCE_MAP.md`
- GitHub Pages workflow: `.github/workflows/pages.yml`

## Data Status

`data/records.json` is sample-only seed data. Live Allen County and Fort Wayne source collection should be added in a later phase after the public source map is reviewed.
